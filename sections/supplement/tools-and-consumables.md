# Tools and consumables

This page lists the minimum tools and consumables needed to execute the procedures in this manual. It is written to support a club workshop: consistent kit, consistent results.

> [!WARNING] Safety
> Composite work produces fine fibre dust. Use PPE: **P2/P3 mask**, eye protection, gloves, and good ventilation. Keep epoxy off skin.

## Core tool kit (maintenance)

- Allen keys (metric)
- Spanners/sockets (metric) including deep sockets for nylocs
- Screwdrivers (Pozidriv/Phillips, flat)
- Pliers, side cutters, adjustable wrench
- Tape measure, calipers/ruler
- Marker pens, masking tape
- Parts trays, small bags, labels
- Microfibre cloths, brushes
- Contact cleaner (for wiring), IPA

## Rigging tools

- Rigging stick / tape measure (span/spread)
- Pitch gauge + correct pitch bushings
- Gate nut tool(s) as required
- Spare washers/spacers, spare bushings
- Witness mark paint pen (if used)

## Seat/track tools

- Correct tools for wheel axles (varies by seat model)
- Spare wheels (as sets), spacers, axle bolts
- Track end stops and fasteners as spares

## Footplate/steering tools

- Spare heel restraint cord/straps
- Steering cable/rope + clamps/ferrules
- Crimp tool (if using ferrules)
- Heatshrink and finishing tape

## Electrical harness tools (coxbox)

- Wire strippers and cutters
- Correct crimp tool for contacts
- Multimeter
- Adhesive‑lined heatshrink (multiple sizes)
- Labels + heatshrink label printer (ideal)

## Composite repair kit (small repairs)

Minimum kit for scratch sealing and small injection repairs:

- Epoxy system suitable for small repairs
- Mixing cups, sticks, scales (preferred)
- Syringes + fine tips
- Peel ply, release film
- Masking tape, release tape
- Sandpaper assortment (80 to 1200 grit)
- Filler (microballoons / fairing filler)
- Clamps and broad clamp pads (foam/wood)
- Heat gun/hair dryer (gentle) for drying and controlled warming

Optional (structural patches / better results):

- Vacuum bag film, tacky tape, breather, perforated release
- Small vacuum pump and fittings

## Consumables by job

### Cleaning and corrosion prevention

- Mild soap
- IPA
- Contact cleaner
- Microfibres and soft brushes

### Fasteners and hardware

- A4/316 stainless fasteners for wet environments
- Flat washers in common sizes (M4/M5/M6/M8)
- Nyloc nuts (replace when worn)
- Anti-seize (for stainless threads that are frequently removed)
- Isolating washers (plastic/nylon) for stainless-on-aluminium interfaces (where appropriate)

### Adhesives and tapes

- Two‑part epoxy (structural)
- Thickened epoxy / filler
- Electrical tape + self‑amalgamating tape (wet environments)
- Adhesive‑lined heatshrink
- Masking tape (good quality)

## Recommended workshop layout

- **Clean bench** for wiring and small parts (no epoxy dust).
- **Composite bench** with extraction/ventilation and disposable bench cover.
- **Label and bag** station for washer stacks and small fasteners.
- **Drying zone** (warm, ventilated) for wet boats and core drying before sealing.
