# Tools and Consumables

## Core hand tools

- Metric spanner set; socket set (common: 8, 10, 13 mm)
- Allen keys (common: 4, 5, 6 mm)
- Screwdrivers (PH2, flat)
- Pliers, side cutters, needle-nose
- Adjustable wrench
- Small torque wrench (optional but helpful)

## Measuring tools

- Tape measure; ruler
- Calipers
- Digital angle finder / inclinometer
- Pitch gauge (oarlock/pin)
- Marker pen; masking tape for labels

## Cleaning supplies

- Mild soap; soft brushes
- Microfibre cloths
- Vinegar for limescale (dilute; rinse thoroughly)
- Contact cleaner (electronics)

## Composite repair kit (club standard)

Useful reference documents:

- [Vacuum bagging (West System, 7th Ed.)](https://eu.westsystem.com/app/uploads/2022/10/VacuumBag-7th-Ed.pdf)
- [Fibreglass manual (West System)](https://eu.westsystem.com/app/uploads/2022/10/Fibreglass-Manual-2015.pdf)

**Materials (as stocked):**

- West System 105/205 epoxy; G5 5-minute epoxy
- Fillers: 403 structural, 406/410 fairing and viscosity control
- Pigments (2–5%)
- Carbon twill ~200 g cloth; carbon/aramid tape ~240 g
- Nomex honeycomb core (3.2 mm x 5 mm typical)
- Clearcoat for bare carbon (e.g., "Fantom Clear")
- Composite adhesive (e.g., VM100)
- Upol Dolphin Glaze for final surfacing
- Air-dry converted paint (traffic white/blue/red, jet black, club green)

**Consumables:** mixing cups, sticks, brushes, nitrile gloves, masking tape, flash tape/tacky tape, plastic squeegees, acetone wipes, IPA spray, sandpaper assortment.

## Electrical kit

- Ratcheting crimper appropriate for the contact series used
- Heat gun
- Adhesive-lined heat shrink
- Multimeter
- Spare connectors and contacts
