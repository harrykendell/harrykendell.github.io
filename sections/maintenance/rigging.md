# Rigging

![What rigging means and what you measure. Rigging spans multiple components. This page is the hub: it defines capability tiers, stop-use criteria, and the audit workflow, then points you to the section that contains the detailed adjustment procedure.](overviews/rigging_overview.svg){size=1}

Rigging is spread across several components (riggers, pins, gates, oars, footplates). This page is the **hub**: it defines what “rigging” means, what you’re allowed to change, and where the detailed adjustment procedures live.

## Capability tiers

- **Beginner:** visual checks; confirm nothing is loose/missing; *no* geometry changes.
- **Intermediate:** measure and restore to the boat’s **rigging sheet**; swap consumables; controlled disassembly/reassembly.
- **Advanced:** change geometry (span/spread, rigger position), repair/replace pins or pin mounts, anything that risks stripping inserts or changing symmetry.

If a boat does not have a current rigging sheet, treat any change beyond **Beginner** as **Advanced** until the sheet exists.

## What counts as rigging

Common parameters (names vary by manufacturer):

- **Gate height** (oarlock height above seat/track reference)
- **Pitch** (stern pitch / lateral pitch depending on bushing system)
- **Span / spread** (distance between pin centres: scull vs sweep)
- **Inboard** (oar collar position)
- **Footplate position** (athlete adjustment, plus any fixed geometry)
- **Steering centring** (for steered boats)

## Stop-use and escalation

Stop-use and escalate immediately if any of the following are true:

- **Rigger moves** relative to hull, or visible cracks/bends.
- **Pin is bent**, threads damaged, or pin mount is loose.
- **Gate latch** does not fully close, or the retainer is missing.
- You cannot restore left/right symmetry using the rigging sheet.

## Tools

- Tape measure or rigging stick (span/spread)
- Pitch gauge + correct pitch bushings (pitch)
- Calipers/ruler + washer pack (gate height)
- Marker + notebook/phone (witness marks + recording)

> [!INFO] Rigging discipline
> Take a photo before you disassemble anything. Bag washer stacks by location. Add witness marks to critical nuts/bolts.

## Daily “rigging sanity check”

[!PROCEDURE:Beginner] Pre‑outing rigging sanity check (2 minutes)
Fast check that nothing safety‑critical is loose or mis‑assembled. This does **not** change geometry; it only prevents obvious failures.

**Tools:** None (gate nut tool if something is loose)

**Steps:**

1. **Gates:** close each gate and confirm the latch fully engages. Pull up on the handle to confirm the oar cannot pop out.
2. **Top nuts/retainers:** confirm the top nut/retainer is tight on every pin.
3. **Riggers:** try to rock each rigger at the hull interface: there should be **no movement**.
4. **Pins:** quick visual: pin vertical, no obvious bend, no missing washers/spacers.
5. **Footplate:** quick check that the footplate clamps are tight and heel restraints are present (see **[Footplates](/#maintenance/footplates)**).
6. **Steering (if fitted):** centre toes and confirm rudder centres; full travel smooth (see **[Footplates](/#maintenance/footplates/steering-wire)**).

**Check:** No looseness, no missing retainers, gates close, steering works. If you find anything you can’t correct immediately, stop‑use and escalate.
[!/PROCEDURE]

## Procedure: full rigging audit and record

[!PROCEDURE:Intermediate] Full rigging audit and record
Systematic check that a boat matches its rigging sheet, and that left/right symmetry is preserved. Do after transport, after any impact, and periodically.

**Tools:** Rigging sheet, tape measure/rigging stick, pitch gauge, calipers/ruler, marker

**Steps:**

1. **Get the rigging sheet** for that boat (paper in boathouse or digital).
2. **Visual/fastener check (stop‑use triggers):**
   - Run **[Rigger and stay inspection](/#maintenance/boats/riggers-stays-and-structural-attachments)**.
   - Run **[Gate safety check](/#maintenance/gates/daily-checks)**.
3. **Match measured geometry to the sheet (restore, don’t invent):**
   - **Gate height:** if off, use **[Adjust gate height](/#maintenance/gates/clean-and-rebuild)**.
   - **Pitch:** if off, use **[Set/verify pitch](/#maintenance/gates/clean-and-rebuild)**.
   - **Span/spread:** measure pin‑centre to pin‑centre. If wrong, **do not adjust** unless you are Advanced (this usually means moving riggers/pins).
   - **Oar inboard:** measure and match across the set using **[Collar inspection and re‑set](/#maintenance/oars/sleeves)**.
4. **Footplate/steering:** confirm the athlete adjustment system is sound using **[Footplate set‑up](/#maintenance/footplates/footplate-adjustment-and-inspection)** and **[Steering functional check](/#maintenance/footplates/steering-wire)**.
5. **Witness marks:** add witness marks to key nuts/bolts (rigger bolts, top nuts) so loosening is obvious.
6. **Record:** date + who checked + measurements (or “matches sheet”) + any parts replaced.

**Check:** Boat matches rigging sheet; left/right symmetry preserved; any deviations recorded and fixed or escalated.
[!/PROCEDURE]
